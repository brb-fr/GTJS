# GTJS
Growtopia server made using [Pogtopia](https://pogtopia.js.org/index.html) with JavaScript

> [!WARNING]
> This project is still in development, using it is not recommended. You can help its development by making a PR.

# Installation 
Make sure you have node/nodejs installed with the dependencies of Pogtopia. 

## Windows:
Make sure to disable a service to access port 80.

`node index.js`

## Linux/MacOS
`sudo node index.js`

# Tests
Tested working on Windows Growtopia version 3.36
